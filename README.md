🎬 Movie Gallery – Movie Management Web Application

Movie Gallery is a web-based application designed to manage and display movie collections. It provides an administration panel for managing movies and administrator accounts, as well as a user platform where visitors can register, log in, and browse available movies.

The application runs locally using XAMPP and an Apache server.

✨ Key Features

🔐 Administration Panel

The administration panel provides tools for managing the movie collection and administrator accounts.

- Admin Login: Secure login for administrators.
- Add Movies: Upload and add new movies to the gallery.
- Update Movies: Edit existing movie information.
- Delete Movies: Remove movies from the gallery.
- Admin Management: Create additional administrator accounts.

👥 User / Subscriber Panel

Users can access the movie gallery through their accounts.

- User Signup: Create a new account.
- User Login: Access the application using registered credentials.
- Home Page: Browse and explore available movies.
- Movie Gallery: View movies displayed in the application.

🚀 How to Run the Project Locally

Prerequisites

- XAMPP
- Apache Server
- PHP
- MySQL (if required by the application)

Installation Steps

1. Install and open XAMPP.

2. Start the Apache server.

3. Start MySQL if the application uses a MySQL database.

4. Copy the project folder into the XAMPP "htdocs" directory.
   
   Example:
   
   C:\xampp\htdocs\Movie-Gallery

5. Open your browser and navigate to:
   
   http://localhost/Movie-Gallery/

6. Access the application and explore the administration and user interfaces.

🎯 Project Purpose

This project demonstrates web application development, user authentication, administrator management, CRUD operations, and file upload functionality.

It provides a practical example of building a movie management system with separate administration and user interfaces.
